# More Minecraft Music

More Minecraft Music is assembled and maintained by **SwordfishBE** for personal use!

Adds the soundtracks from Music And Melody and the More Music pack to Minecraft's normal background music selection, alongside vanilla music.
No custom player, menu, settings, playlists, combat triggers, or network handlers.

## Build

Run `gradlew.bat build` on Windows, or `./gradlew build` on other systems. Java 25 is required.
Gradle downloads the build dependencies on the first run.
Use `--offline` when the dependencies are already cached.

All required music and icon resources are included in `src/main/resources`.
The build needs no original input archives, import scripts, or external project folders.

Original creator and soundtrack credits are in `CREDITS.md`, also included in the mod jar.
